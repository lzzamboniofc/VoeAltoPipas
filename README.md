Estrutura:

## Antes de publicar
1. Em `js/script.js`, preencha `WHATSAPP_NUMBER` com o número oficial (DDI + DDD + número, somente dígitos).
2. Troque as composições abstratas dos destaques por fotos próprias da loja quando disponíveis.
3. Confirme endereço, horário e demais dados de contato.
4. O endereço usado no protótipo foi encontrado em diretório público: Rua João Januário Pamplona, 538, Jardim Santa Tereza, Itu/SP.
5. Instagram: @voealtopipas.

O projeto usa Bootstrap 5 apenas como apoio e mantém a direção visual em CSS próprio.
